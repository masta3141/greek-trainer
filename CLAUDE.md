# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

"Griechisch Trainer" — an installable, offline-capable PWA for learning Modern Greek vocabulary by CEFR level (A1–C2), built step by step as a sibling of `../chinese-trainer` (the HSK Trainer). Follow that app's conventions and look there first when adding a feature it already has (session algorithm, progress model, stats, backup, Gemini, …). Comments and code are in English; the UI is German (reference) and English.

Current state: three tabs — **Vokabeln** (word grid like the HSK app's pool grid: one tile per word, empty until practised, then filled with its progress colour; search, filter panel with max level / only pool / only streak / progress buckets, tap mode Info / ✓ Pool / 🔥 Streak), **Karten** (free practice + Power-Streak, ported 1:1 from the HSK app, incl. Gemini example sentences) and **Geschichten** (Gemini stories, reader with word recognition, narration, speech recognition; no audio recordings) — plus the settings drawer. Not ported on purpose (yet): Satzinseln, Audio tab/Gemini TTS, Statistik tab, welcome dialog, mobile swipe carousel. Speech output uses **browser voices only** (the user's decision): `greekVoices()` ranks them by `voiceScore()`, `settings.voiceName` '' = best automatically.

There is **no build system, package manager, linter, or unit tests**. Plain ES5-style JavaScript (`var`, `function`, no modules) in classic `<script>` files sharing the global scope. To run locally:

```
python3 -m http.server 8000
```

**Smoke test:** `node tools/smoke-test.js` (Node 22+, Chrome/Chromium; `--show` to watch) serves the app, opens it in a throwaway headless Chrome profile, clicks through all flows and fails on any JS error, broken expectation or third-party request. **Run it after every change**; extend it when adding features.

## Files

- `index.html` — markup plus `<link>`/`<script>` tags.
- `css/app.css` — all styles; colors are tokens on `:root` with dark-mode overrides (same palette as the HSK app, Aegean blue `--sea` as accent, `--lv-a1`…`--lv-c2` for level badges).
- `data/forms.json` — `{folded word form: word id}` for all lemmas and their inflected forms (from Wiktionary's tables, ~87k entries); fetched on first use by `loadForms()` in js/stories.js to find words in sentences (`segmentSentence`, `wordsInSentence`). Generated together with words.js.
- `data/words.js` → `WORDS` (7378 words), generated by `tools/build-words.py` — a single huge line, **never Read or grep it without limiting output** (`| cut -c1-200`). Sources and licenses: `data/README.md` (KELLY is CC BY-NC 4.0, glosses CC BY-SA).
  - Word shape: `{id, l: 'A1'..'C2', w: Greek lemma, a: article (nouns: ο/η/το), r: romanization, e: English gloss, p: part of speech code, x: phrases (MWE), f: KELLY frequency rank}`; empty fields are omitted. Ids 1..N follow level, then frequency rank.
- `tools/build-words.py` — `python3 -I tools/build-words.py <KELLY_EL.xlsx> <kaikki Greek .jsonl.gz> [out.js] [--missing]`; download URLs are in its docstring. `tools/glosses-extra.tsv` holds hand-written glosses (word<TAB>gloss) for words Wiktionary lacks and overrides; `--missing` lists words still without a gloss.
- `js/*.js`, loaded in this order: `core` (levels, storage keys, settings, progress, fonts, activity, `esc`, `fold`, `levelToColor`, toast) → `i18n` → `gemini` (key, model detection, `callGemini`, example sentences in IndexedDB `grtrain_examples_db`) → `speech` (voice ranking, `speak`/`speakAsync`, narration, speech recognition) → `session` (pool, free-practice round, pause/resume) → `streak` (Power-Streak + own SRS) → `cards` (stats strip, start screen, card) → `stories` → `vocab` → `settings` (drawer, import/export) → `backup` (full backup) → `navigation` (tabs, `renderAll`) → `init` (must stay last).
- Ported code keeps the HSK app's structure and comments; when changing session/streak/stories logic, check whether `../chinese-trainer` has the same code and keep them in step. Sentences are `{g, r, e}` (Greek, romanization, English) instead of the HSK app's `{h, p, e}`; Gemini answers in `GREEK|ROMANIZATION|ENGLISH` lines.
- `sw.js` — service worker, network first, cache as offline fallback. **Bump `CACHE_NAME`** when any shell file changes and keep `APP_SHELL` in sync with `index.html` (the smoke test checks this).
- `manifest.json`, `icon.svg` — PWA metadata (no PNG icons yet).

## Working with the code

- Every `js/*.js` starts with `"use strict";`. Top-level statements may only use names from the same or an earlier file; function bodies can use anything.
- `localStorage` keys are prefixed `grtrain_` and versioned `_v1` (settings, progress, fonts, streak, stories, pool overrides, paused round, activity, Gemini key/model). The full backup (`grtrain-backup-v1`) saves every `grtrain_*` key except the Gemini key/model plus the example sentences — new storage must stay covered by it.
- Progress model as in the HSK app: `progress[id] = {lvl 0..100, lr, seen}`; missing entries count as level 0 (no seeding). The pool is the first `settings.pool` words in id order plus/minus `poolOverrides`.
- Search uses `fold()` (lowercase, strip accents, ς→σ) on Greek, romanization, phrases and gloss; results are ranked exact > prefix > contains.
- The vocab grid renders all ~7400 tiles at once (as the HSK app does); `updateWordCell(id)` re-renders a single tile after a rating, `renderVocab()` everything. Grid filters live in `grtrain_grid_filter_v1`.
- **When adding UI text, add the key to both `de` and `en`** in `js/i18n.js`.
