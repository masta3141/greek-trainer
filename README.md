# Griechisch Trainer

Installierbare, offline-fähige Web-App (PWA) zum Lernen neugriechischer Vokabeln nach GER-Stufen A1–C2:
Vokabel-Raster mit Lernfortschritt, Karteikarten (freies Üben + Power-Streak mit Wiederholungsplan)
und mit Gemini erzeugte Geschichten und Beispielsätze.

**App:** https://masta3141.github.io/greek-trainer/

Wortliste: KELLY word-list Greek (ILSP / Athena RC, CC BY-NC 4.0), Übersetzungen und Wortformen aus
Wiktionary (CC BY-SA) — Details in [data/README.md](data/README.md).
